# Словесные Былины

Словесная головоломка в жанре славянского фэнтези для платформы Яндекс Игры.

Составляйте слова из букв, сражайтесь с персонажами славянского фольклора: Лешим, Бабой-Ягой, Змеем Горынычем и другими. 250+ уровней, боевой пропуск, ежедневные задания.

## Структура проекта

```
├── game/                    # Игра
│   ├── index.html          # Главный HTML-файл
│   ├── css/style.css       # Стили (славянская тематика)
│   ├── js/
│   │   ├── main.js         # Основной цикл игры
│   │   ├── localization.js # Тексты на русском языке
│   │   ├── yandex.js       # Интеграция с Яндекс SDK
│   │   ├── levels.js       # Генерация 250+ уровней
│   │   ├── combat.js       # Боевая система
│   │   ├── battlepass.js   # Боевой пропуск (Free/Premium)
│   │   └── audio.js        # Звуковая система
│   ├── assets/             # Изображения
│   └── metadata.json       # Метаданные для публикации
├── CONCEPT.md              # Концепт-документ
├── INSTRUCTION.md          # Инструкция для ИИ
├── start_game.bat          # Запуск на Windows
└── README.md               # Этот файл
```

## Запуск игры

### Windows
Дважды кликните `start_game.bat` — скрипт проверит наличие Python и запустит сервер.

### Вручную (любая ОС)
```bash
cd /home/user/yandexgame
python3 -m http.server 8080
```
Откройте в браузере: http://localhost:8080/game/

## Технологии
- HTML5 + CSS3 + JavaScript (Vanilla)
- Яндекс Games SDK v3
- Web Audio API
- Адаптивный дизайн (ПК и мобильные)

## Требования платформы
- ✅ Автоопределение языка через SDK (только русский)
- ✅ Кроссплатформенность (ПК + мобильные)
- ✅ Внутриигровая реклама (rewarded + interstitial)
- ✅ Боевой пропуск (Free + Premium)
